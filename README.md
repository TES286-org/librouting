# librouting

A platform-independent routing protocol library in Rust. It parses, speaks
and computes routes for BGP, OSPFv2/v3, Babel, LDP and the MPLS/SRv6 label
codecs, and it is verified against BIRD 2 and FRR 10.

The protocol crates are transport-free: they never open a socket and never
touch a routing table. The embedder owns bytes, time and the kernel; the
library owns protocol state. `lr-daemon` is the reference embedder — a
complete program built only from the public library API, so anything the
daemon does is something you can do.

## Quick start

```sh
git clone https://github.com/TES286-org/librouting.git
cd librouting
cargo build --release -p lr-cli
# → target/release/lr          inspection CLI
# → target/release/lr-daemon   reference daemon
# → target/release/lrctl       operational CLI
```

Bring up two BGP speakers on loopback. Speaker A listens and originates a
prefix; speaker B connects and learns it:

```sh
# Terminal 1 — speaker A
lr-daemon --local-as 64512 --peer-as 64513 --router-id 10.0.0.1 \
          --listen 127.0.0.1:1179 --local-address 192.0.2.1 \
          --network 203.0.113.0/24

# Terminal 2 — speaker B
lr-daemon --local-as 64513 --peer-as 64512 --router-id 10.0.0.2 \
          --peer 127.0.0.1:1179 --local-address 192.0.2.2
```

B reaches Established and installs `203.0.113.0/24` with A's address as
the next hop. Both processes log the session state and the route as it
lands.

The daemon also reads BIRD 2 and FRR 10 configuration files directly
(`lr-daemon --config bird.conf`), runs OSPF, Babel, LDP, BFD, BMP and
RPKI-RTR, and multiplexes several protocols in one process
(`--protocol bgp,ospf`). The native `.lr` configuration DSL carries
configuration and policy in one file; `templates/daemon.lr` is the
fully commented reference.

Next: [`docs/tutorial.md`](docs/tutorial.md) to embed the library,
[`docs/lr-daemon.md`](docs/lr-daemon.md) to run it.

## Crates

| Crate | Purpose |
| --- | --- |
| `lr-core` | Addresses, codec traits, generic FSM, RIB traits, timers, attributes |
| `lr-bgp` | BGP-4 codec, peer FSM, capabilities, best-path, roles, extensions |
| `lr-ospf` | OSPFv2/v3 codec, LSAs, LSDB, neighbor FSM, SPF, areas, authentication |
| `lr-babel` | Babel codec, TLVs, neighbor FSM, route table, MAC authentication |
| `lr-ldp` | LDP codec and state machines |
| `lr-mpls` | MPLS label and label-stack codec |
| `lr-srv6` | SRv6 SID, locator and behavior |
| `lr-rib` | Adj-RIB-In, Adj-RIB-Out, Loc-RIB, selection, cross-protocol merging |
| `lr-policy` | Route maps, prefix/AS-path/community lists, hooks, safety net, filter DSL |
| `lr-router` | Router instance: sessions, scheduler, event dispatch, RIB pipeline |
| `lr-bfd` | BFD codec and session FSM |
| `lr-bmp` | BGP Monitoring Protocol codec and sink |
| `lr-mrt` | MRT dump format |
| `lr-damping` | Route flap damping |
| `lr-osroute` | OS route-table backends and protocol transports |
| `lr-ffi` | C ABI (header generated by cbindgen) |
| `lr-cli` | The `lr`, `lr-daemon` and `lrctl` binaries |
| `lr-tests` | Cross-crate integration tests |

Every protocol crate has the same three layers:

| Layer | What it is | Example |
| --- | --- | --- |
| 1 | Stateless wire codec | `BgpCodec`, `BfdCodec` |
| 2 | Peer FSM plus a transport abstraction | `BgpPeer::step` |
| 3 | Orchestrator: sessions and RIB | `DefaultRouter` |

Layer 1 suits analyzers and test harnesses. Layer 2 suits embedders that
already own an event loop. Layer 3 gives you the whole pipeline.
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) explains how they fit
together.

## Bindings

The C ABI in `lr-ffi` (header: `include/lr_ffi.h`, C++ wrapper:
`include/librouting.hpp`) lets C, C++, Go and Python programs use the
library without a Rust toolchain at runtime.

| Language | Guide | Code |
| --- | --- | --- |
| C | [`docs/bindings/c.md`](docs/bindings/c.md) | `include/lr_ffi.h` |
| C++ | [`docs/bindings/cpp.md`](docs/bindings/cpp.md) | `include/librouting.hpp` |
| Go | [`docs/bindings/go.md`](docs/bindings/go.md) | `bindings/lr-go/` |
| Python | [`docs/bindings/python.md`](docs/bindings/python.md) | `bindings/lr-python/` |

The design behind the C surface is in
[`docs/ffi_design.md`](docs/ffi_design.md).

## Status

The library is pre-1.0 and in its release freeze: the public Rust API and
the C ABI are frozen for the 1.0 cut, so a breaking change ships as a new
release candidate and restarts the freeze clock. The workspace version
lives in `[workspace.package] version` in `Cargo.toml`; that file is the
source of truth.

[`docs/STATUS.md`](docs/STATUS.md) lists what is implemented and what is
not. [`docs/ROADMAP.md`](docs/ROADMAP.md) lists what is planned.
BGPsec is the one protocol deliberately left out of scope.
